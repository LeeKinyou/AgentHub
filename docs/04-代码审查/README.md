## 审查方法

AI 对后端代码进行全面审查，覆盖以下维度：

- **安全性**：认证授权、凭据管理、权限校验
- **逻辑正确性**：数据校验、边界处理、并发安全
- **架构合理性**：模块耦合、依赖管理、扩展性
- **代码质量**：命名规范、分页设计、索引优化

## 问题分级标准

| 优先级 | 含义 | 处理要求 |
|--------|------|----------|
| P0 | 严重安全漏洞或数据损坏风险 | 必须立即修复 |
| P1 | 逻辑 Bug，影响功能正确性 | 尽快修复 |
| P2 | 架构缺失，影响扩展性 | 规划修复 |
| P3 | 代码质量，影响可维护性 | 择机修复 |
