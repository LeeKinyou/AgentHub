# AgentHub — 产品设计文档 (PRD)

> 最后更新：2026-05-28

---

## 一、产品定位

AgentHub 是一个**以即时通讯（IM）聊天为核心交互范式的多 Agent 协作平台**。

用户无需理解 "prompt engineering"、"pipeline"、"workflow orchestration" 等底层概念——他们只需要像在微信群里聊天一样，发送一条消息、@ 一个智能体，就能完成从需求描述到网页部署的全流程。

---

## 二、核心功能

### 2.1 IM 聊天式交互

| 功能 | 说明 | 状态 |
|------|------|------|
| 对话列表 | 左侧会话列表，支持新建、搜索，按最近活跃排序 | ✅ 已实现 |
| 单聊模式 | 1v1 与单个 Agent 对话 | ✅ 前端就绪 |
| 群聊模式 | 一个对话中包含多个 Agent，Orchestrator 自动协调 | ✅ 前端就绪 |
| 富消息类型 | 文本、代码块、Diff 卡片、部署状态卡片 | ✅ 已实现 |
| 消息操作 | 复制、Pin、重新生成 | ✅ 已实现 |
| 上下文管理 | @Mention + Context Chips + 文件拖拽 | ✅ 已实现 |

### 2.2 Agent 协调器 (Orchestrator)

| 能力 | 说明 | 状态 |
|------|------|------|
| 任务拆解 | LLM 自动理解意图，分解为子任务 | ✅ 已实现 |
| 产物聚合 | 汇总各子 Agent 产出 | ✅ 已实现 |
| 调度管理 | 顺序执行 + 失败降级 | ✅ 已实现 |
| 并行调度 | 无依赖步骤并行执行 | ⬜ 待实现 |

### 2.3 多 Agent 接入

| 能力 | 说明 | 状态 |
|------|------|------|
| 统一适配器层 | BaseAdapter 抽象，屏蔽 API 差异 | ✅ 已实现 |
| Claude Code 适配器 | Anthropic API 流式调用 | ✅ 已实现 |
| 自定义 Agent | 支持 Anthropic/OpenAI + MCP 工具调用 | ✅ 已实现 |
| Codex/OpenCode | 适配器占位 | ⬜ 待实现 |

### 2.4 产物预览与编辑

| 能力 | 说明 | 状态 |
|------|------|------|
| 代码编辑器 | Monaco Editor 风格，支持语法高亮 | ✅ 已实现 |

## 三、用户旅程

```
用户新建对话
  → 输入："帮我做一个个人简历网站，风格偏极简"
  → 系统自动匹配 Orchestrator Agent
  → Orchestrator 拆解任务，@ 前端工程师 Agent 生成页面骨架
  → @ UI 设计师 Agent 优化视觉样式
  → @ 部署 Agent 一键发布预览链接
  → 用户在聊天流中看到代码 Diff、网页预览卡片、部署状态卡片
  → 用户点击 "Apply" 应用修改，或点击预览链接查看成品
```

---

## 四、创新亮点

1. **IM 聊天范式**：将复杂的多 Agent 协作封装进最熟悉的对话界面
2. **选中即修改**：在编辑器中框选代码 → 直接在聊天中输入修改指令 → Agent 精准修改
3. **可视化编排流**：实时展示 Orchestrator 如何拆解和分派任务
4. **Memory Bank 机制**：AI 跨对话保持上下文连续性
