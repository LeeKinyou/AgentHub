## 一、认证与授权体系

### 1.1 设计方案：Redis + JWT 双 Token

采用 Access Token + Refresh Token 双令牌机制：

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│  Client  │────▶│  FastAPI  │────▶│   Redis  │
│ (Browser)│◀────│  Server   │◀────│ (Token)  │
└──────────┘     └──────────┘     └──────────┘
     │                │
     │  POST /auth/login (username + password)
     │◀───────────────│
     │  { access_token, refresh_token }
     │                │
     │  GET /api/xxx  (Authorization: Bearer <access_token>)
     │───────────────▶│
     │                │  JWT 解码 + Redis 验证
     │◀───────────────│  200 / 401
     │                │
     │  POST /auth/refresh (refresh_token)
     │───────────────▶│  Redis 验证 refresh_token
     │◀───────────────│  新 access_token + refresh_token
     │                │
     │  POST /auth/logout
     │───────────────▶│  Redis 写入黑名单 (access_token JTI)
     │◀───────────────│  删除 refresh_token
```

### 1.2 Token 策略

| Token | 存储位置 | 有效期 | 用途 |
|-------|----------|--------|------|
| Access Token (JWT) | 客户端内存/Header | 30 分钟 | API 请求认证 |
| Refresh Token | Redis `refresh:{user_id}` | 7 天 | 刷新 Access Token |
| Token 黑名单 | Redis `bl:{jti}` | = Access Token 剩余有效期 | 登出/改密后立即失效 |

### 1.3 JWT Payload 结构

```json
{
  "sub": "user_uuid",
  "username": "kinyou",
  "iat": 1717401600,
  "exp": 1717403400,
  "jti": "unique_token_id"
}
```

### 1.4 Redis Key 设计

```
# Refresh Token（用户维度，单设备登录）
refresh:{user_id}  →  refresh_token_string  (TTL: 7d)

# Access Token 黑名单（登出/改密时写入）
bl:{jti}  →  1  (TTL: access_token 剩余秒数)

# 未来扩展：在线状态
online:{user_id}  →  1  (TTL: 5min, WebSocket ping 续期)
```

### 1.5 API 端点设计

| 方法 | 路径 | 说明 | 认证要求 |
|------|------|------|----------|
| POST | `/api/auth/register` | 用户注册 | 无 |
| POST | `/api/auth/login` | 用户登录 | 无 |
| POST | `/api/auth/refresh` | 刷新 Token | Refresh Token |
| POST | `/api/auth/logout` | 用户登出 | Access Token |
| GET | `/api/auth/me` | 获取当前用户信息 | Access Token |

### 1.6 依赖注入链

```python
# core/auth.py

async def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: AsyncSession = Depends(get_db),
    redis: Redis = Depends(get_redis),
) -> User:
    """从 JWT 中解析用户，验证未被黑名单"""
    payload = decode_access_token(token)
    jti = payload.get("jti")
    # 检查黑名单
    if await redis.exists(f"bl:{jti}"):
        raise HTTPException(401, "Token has been revoked")
    user = await db.get(User, payload["sub"])
    if not user:
        raise HTTPException(401, "User not found")
    return user
```

### 1.7 WebSocket 认证

WebSocket 无法携带 Authorization Header，改用查询参数传递 Token：

```
ws://localhost:8000/ws?session_id={session_id}&token={access_token}
```

连接握手时验证 Token，失败则返回 `4003` 关闭码。

### 1.8 授权模型

当前阶段采用 **资源归属校验**（非 RBAC），规则如下：

| 资源 | 规则 |
|------|------|
| User | 只能读写自己的 User 记录 |
| Session | `session.user_id == current_user.id` |
| AgentProfile | `agent.user_id == current_user.id` |
| Message | 通过 Session 归属间接校验 |
| WebSocket | 连接时校验 session 归属 |

```python
# 通用授权依赖
async def verify_session_owner(
    session_id: UUID,
    current_user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
) -> Session:
    session = await db.get(Session, session_id)
    if not session or session.user_id != current_user.id:
        raise HTTPException(403, "Access denied")
    return session
```

## 五、安全加固

### 5.1 API Key 加密存储

**问题**：`agent_config.api_key` 在数据库中明文存储。

**方案**：使用 Fernet 对称加密，密钥从环境变量读取。

```python
# core/crypto.py
from cryptography.fernet import Fernet
from .config import get_settings

def get_fernet() -> Fernet:
    settings = get_settings()
    return Fernet(settings.ENCRYPTION_KEY.encode())

def encrypt_field(plaintext: str) -> str:
    return get_fernet().encrypt(plaintext.encode()).decode()

def decrypt_field(ciphertext: str) -> str:
    return get_fernet().decrypt(ciphertext.encode()).decode()
```

```python
# 存储时自动加密
class AgentProfileService:
    @staticmethod
    async def create(db: AsyncSession, user_id: UUID, data: AgentProfileCreate):
        profile = AgentProfile(...)
        if data.agent_config and data.agent_config.api_key:
            data.agent_config.api_key = encrypt_field(data.agent_config.api_key)
        profile.agent_config = data.agent_config.model_dump()
        ...
```

## 七、错误处理统一化

### 7.1 统一响应策略

**方案**：REST API 使用 HTTP 状态码 + `HTTPException`，WebSocket 使用自定义错误码。

```python
# REST API
@router.get("/{user_id}", response_model=ApiResponse[UserRead])
async def get_user(user_id: UUID, ...):
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    return ApiResponse(data=UserRead.model_validate(user))
```

```python
# WebSocket 保持自定义错误码
WS_ERROR_CODES = {
    "AUTH_FAILED": 4001,
    "SESSION_NOT_FOUND": 4004,
    "MESSAGE_TOO_LONG": 4013,
    "RATE_LIMITED": 4029,
    "INTERNAL_ERROR": 5000,
}
```

### 9.2 错误码扩展

| 错误码 | 含义 | 触发场景 |
|--------|------|----------|
| `AUTH_FAILED` | 认证失败 | Token 无效/过期/被黑名单 |
| `SESSION_NOT_FOUND` | 会话不存在 | session_id 无效或不属于当前用户 |
| `MESSAGE_TOO_LONG` | 消息超长 | content 超过 100KB |
| `RATE_LIMITED` | 频率限制 | 短时间内发送过多消息 |
| `AGENT_BUSY` | Agent 忙碌 | 同一 session 并发消息 |
| `INTERNAL_ERROR` | 内部错误 | 未预期的异常 |
